# NS6 MIDI input read depth, 2026-10-16

The original Ploytec kext's `AJ` startup queues 16 asynchronous bulk IN reads (`bulkRead` loop in `docs/diagnostics/2026-10-16-midi-control-e0/ghidra-midi-protocol.c`). The current macOS userspace driver queues four. In the original-driver `teste total.pcapng`, endpoint0x83 on device address10 has 11,464 successful completions and no failed transfers across14:04:09–14:09:22. The longest interval between successful completions is68.872s. On previous device addresses8 and9, a `NotResponding` is followed by14 `Aborted` requests during controller reconnect; this confirms the vendor also has multiple requests outstanding, not that its normal idle operation stalls. Packetless idle alone is insufficient to explain the userspace driver's repeated `NotResponding`.

Isolated hardware experiment 0.2.134 changes only the number of pending MIDI reads from4 to16. The recovery mask already uses32 bits; the compile-time limit now asserts1–32. Build switch `NS6_MIDI_READ_SLOTS` defaults to4, with16 enabled only for this package. The driver logs the queued slot count at session start. Neither USB audio scheduling nor MIDI error recovery was changed. If the first `NotResponding` persists, especially with no MIDI successes beforehand, read depth is not the cause; the existing clear/abort cascade may be larger with16 slots. Stop the test if controls stop responding or the LED/audio worsens. Compare first-error timing, successful completion count, pipe clears, callback gaps and audio errors against0.2.130.

The package also fixes a separate installer issue: `package-components.plist` makes both HAL and Status bundles nonrelocatable, skips version gating, and atomically upgrades them. The preinstall no longer deletes the standard Status app. `pkgbuild` metadata for0.2.134 confirms both bundle IDs in `upgrade-bundle`, with empty `bundle-version` and `relocate`. Before the read-depth change, the rebuilt0.2.133 binary matched the0.2.130 binary except for32 bytes in its code-signature area. The0.2.134 diagnostic build uses16 slots and logs the slot count on hardware.
